PBX Call Simulator (V5 Site-Only Routing)

Site-only answering: Each clinic answers only calls to its own number, only during its own business hours. There is no cross-site coverage and no lunch closure.
Ring order: The Order 1 primary phone rings for 90 seconds (Stratus Agent Ring Timeout max). Then the Order 2 failover group is added. If nobody answers, the caller stays on hold in the queue (no voicemail).
Closed hours: Outside that clinic's hours, the route user forwards to Main Routing User 8903, which sends the call to After-Hours AA 8163.
Menu: Press 4 for refill info or 5 for clinic info. Both play, then return to the same clinic's queue. Staying on the line goes straight to the queue.
